# Plaque Designer

Konfigurator personalizowanych tabliczek przeznaczonych do druku 3D.

## Uruchomienie

```bash
npm install
npm run dev
```

## Weryfikacja

```bash
npm run typecheck
npm test
npm run build
```

Projekt jest rozwijany etapami zgodnie z [planem implementacji](./docs/IMPLEMENTATION_PLAN.md).
